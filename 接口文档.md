#### get_info 获取指定战场的详细信息

```
GET /xdc/get_info HTTP/1.1
```

参数：

| 字段    | 类型     | 说明     |
|-------|--------|--------|
| warId | string | 指定战场id |

响应：

| 字段               | 类型         | 说明       |
|------------------|------------|----------|
| circleLevel      | int        | 圈数       |
| circlePosX       | float64    | 毒圈中心x坐标  |
| circlePosY       | float64    | 毒圈中心y坐标  |
| circleRadius     | float64    | 毒圈半径     |
| airlineStartPosX | float64    | 航线初始坐标x  |

| airlineEndPosX   | float64    | 航线终止坐标y  |
| customRoomName   | string     | 自定义房间名字  |
| playerInfoList   | playerInfo | 玩家详细信息列表 |

#### get_kill_info 获取指定战场的击杀信息

```
GET /xdc/get_kill_info HTTP/1.1
```

参数：

| 字段    | 类型     | 说明     |
|-------|--------|--------|
| warId | string | 指定战场id |

响应：

| 字段         | 类型      | 说明          |
|------------|---------|-------------|
| attackID   | int64   | 攻击者pid      |
| weapon     | string  | 使用武器        |
| beAttackID | int64   | 被攻击者pid     |
| isRealDie  | bool    | 攻击结果（击倒/淘汰) |
| gameTime   | float64 | 游戏时间        |


响应示例：

[map[attackID:0 beAttackID:3.3040338e+07 gameTime:1165.44445800781 isRealDie:true warId:e9854047c5494206ff8f386f28d2e3fd_1 weapon:DuQuan]]



#### get_score_info 获取比赛结果

```
GET /xd/get_score_info HTTP/1.1
```

参数：

| 字段                | 类型    | 说明               |
|-------------------|-------|------------------|
| competitionInfoId | int32 | 赛事Id             |
| subId             | int32 | 小组赛Id，为 0 代表查询所有 |
| gameId            | int32 | 局数Id，为 0 代表查询所有  |

响应：

| 字段            | 类型          | 说明   |
|---------------|-------------|------|
| status        | string      | 上报结果 |
| scoreInfoList | []ScoreInfo | 比赛结果 |

ScoreInfo 结构

| 字段                | 类型          | 说明    |
|-------------------|-------------|-------|
| id                | int32       | id    |
| warId             | string      | 战场Id  |
| competitionInfoId | int32       | 赛事Id  |
| subId             | int32       | 小组赛Id |
| gameId            | int32       | 局数Id  |
| teamId            | int32       | 队伍Id  |
| teamName          | string      | 队伍名称  |
| rank              | int32       | 排名    |
| rankScore         | int32       | 排名分   |
| KillScoreList     | []KillScore | 淘汰分列表 |

KillScore 结构

| 字段             | 类型      | 说明        |
|----------------|---------|-----------|
| uid            | string  | uid       |
| nick           | string  | 昵称        |
| totalKill      | int16   | 淘汰数       |
| assists        | int16   | 助攻数       |
| damage         | float64 | 伤害量       |
| killScore      | int32   | 淘汰分       |
| survive        | float64 | 生存时长      |
| driveDistance  | float64 | 载具行驶距离(米) |
| marchDistance  | float64 | 非开车距离(米)  |
| hitBulletNum   | int32   | 射击子弹总数    |
| bulletTotalNum | int32   | 命中子弹总数    |
| competitionNum | int32   | 参赛场数      |
